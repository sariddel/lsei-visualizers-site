# LSEI Scenario Visualizers

Two self-contained web tools from the CSA LSEI architecture study (SpaceDIRT Inc, project 136),
served as tabs on one page:

- **Landed Mass** — how many landings of which vehicles, year by year, to land *X* tonnes on the Moon.
- **Power Architecture** — what *X* kW of surface power takes, and whether the landed-mass budget can carry it.

Open `index.html` (or the GitHub Pages URL). Deep links: `#landed`, `#power`.
Each tool also works standalone: `landed_mass_visualizer.html`, `power_architecture_visualizer.html`.
